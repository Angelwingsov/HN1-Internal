An internal cheat for **Hello Neighbor** (DirectX 11, x64).

## Features

- **ESP** — Neighbor box, distance, and AI state; key item highlights.
- **Noclip** — Fly through walls and map boundaries.
- **Invisibility** — Neighbor and cameras ignore you.
- **Camera** — Third-person view and custom FOV.
- **Menu** — ImGui interface with DLL unload support.

## Hotkeys

| Key | Action |
| :--- | :--- |
| `Insert` | Toggle Menu |
| `F1` | Noclip |
| `F2` | Invisibility |
| `F3` | Third Person |
